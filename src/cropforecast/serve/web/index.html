1 Abstract

Conventional crop-disease systems classify a leaf photograph after symptoms become visible, ignore the meteorology that governs infection, and treat every field in isolation. This work implements a unified framework that fuses a frozen vision transformer, engineered agro-meteorological features derived from real reanalysis data, and a spatio-temporal graph over 37 Indian production districts, trained under a physics-informed loss that encodes agronomic constraints. The system forecasts disease risk at 1, 3, 5 and 7 day horizons.

On evaluation integrity. PlantVillage photographs each physical leaf 2.65 times on average. A random split therefore places near-duplicate views of the same leaf on both sides — affecting 35,246 of 54,305 images (65%). Every figure reported here uses a leaf-disjoint split with zero shared leaf groups.

4 Proposed Methodology

The architecture proceeds in six blocks. Each is implemented as an independent module.

4.1  Agronomic knowledge base

Temperature response follows the Analytis beta model, which is zero outside the cardinal temperatures and peaks at the optimum. The moisture term takes a different functional form per organism, so several pathogens respond in opposite directions to the same weather — this is what makes the climate stream informative.

4.2  Physics-informed loss

The loss never sees the epidemiological model used to construct the benchmark; that would be circular. It states only weak directional facts, so the network must still learn the quantitative relationship from data.

5 Dataset and Spatio-Temporal Grounding

PlantVillage ships no coordinates and no timestamps, yet the graph needs a location and the climate layer needs a date. Each leaf is therefore placed at a farm that genuinely grows that crop, on a date inside that crop's real growing season, weighted by whether the weather actually recorded there was epidemiologically plausible for the labelled disease. The draw is stochastic with a probability floor, so the mapping is noisy and cannot be inverted.

7.3  When the graph earns its place

With every farm submitting a photograph, a frozen transformer already identifies the disease at roughly 98% accuracy and message passing has little headroom. The operational case for a graph is different: farms that submit no photograph have no visual evidence, and only their neighbours can supply it. This experiment masks the vision stream for a growing fraction of farms.

Run scripts/08_missing_data.py.

7.4  A negative result, reported

The graph neural network does not improve accuracy on this benchmark. Removing it and replacing the encoder with a plain MLP over the same fused features raises macro-F1 and forecast R². This held across two independently constructed versions of the dataset, at five levels of observation sparsity, and for both GraphSAGE and GCN. It is a measured result, not a tuning failure we stopped short of fixing.

Two things explain it, and both are properties of the problem rather than of the code:

  • No headroom on diagnosis. A frozen ViT-B/16 reaches ~98.8% accuracy on the leaf-disjoint test set from the image alone. Averaging in neighbouring farms — which carry different diseases — can only dilute a signal that is already almost saturated.
  • A farm's own state is nearly a sufficient statistic. In the simulated epidemic, a farm's current infection pressure predicts its pressure three days later at r = 0.83. Its neighbours reach r = 0.85 — better, but the incremental information beyond the farm's own state is small, and the node already observes that directly through its leaf image and weather.

The graph is retained as the default configuration because it is the architecture this project set out to implement, and because its cost is now quantified rather than assumed. A spatial model should be expected to pay for itself where per-farm evidence is weak or absent; establishing the conditions under which it does is the natural next experiment.

8 Conclusion and Future Scope

Conclusion

  • A frozen vision transformer provides strong disease features at low training cost.
  • Engineered agro-meteorology contributes measurable, independently verified signal.
  • A physics-informed loss enforces agronomic behaviour without overriding the data.
  • Multi-horizon forecasting turns detection into anticipation.

Future scope

  • Drone and satellite multispectral imagery as additional node features.
  • Live weather forecast forcing rather than reanalysis at inference time.
  • IoT canopy sensors for measured, rather than inferred, leaf wetness.
  • Field validation against recorded outbreak records.
