1 Overview

The problem

  • Existing systems classify a leaf after symptoms appear
  • They ignore weather, which is what drives infection
  • They treat every field as isolated

Our approach

  • Leaf image → what disease is present
  • Real weather → will infection spread
  • Neighbouring farms → is it arriving
  • Forecast 1, 3, 5, 7 days ahead

Why climate matters

  • Late blight → cool + wet (17°C)
  • Powdery mildew → humid air, rain kills it
  • Spider mites → hot + dry
  • Opposite responses; pixels cannot see this
Evaluation integrity. PlantVillage photographs each leaf 2.65× on average, so a random split leaks 35,246 of 54,305 images (65%). All results use leaf-disjoint splits — zero shared leaves.

4 Methodology

4.1  Agronomic knowledge base

  • Analytis beta model for temperature response
  • Moisture term differs per organism
  • Several pathogens respond in opposite directions

4.2  Physics-informed loss

  • Risk must rise with leaf wetness and humidity
  • Dry air must suppress fungal risk
  • Risk must be smooth across connected farms
  • Uncertainty must grow with horizon

7.4  A negative result, reported

The graph does not improve accuracy on this benchmark.
  • Replacing it with a plain MLP raises macro-F1 and risk R²
  • Held across 2 datasets, 5 sparsity levels, 2 encoders
  • A measured result, not a tuning failure

Why

  • No headroom. A frozen ViT already hits ~98.8% from the image alone; averaging in neighbours with different diseases only dilutes it
  • Own state is near-sufficient. A farm predicts its own risk in 3 days at r = 0.83; neighbours reach 0.85 — better, but barely

The graph stays as the default because it is the architecture this project set out to build, and its cost is now measured rather than assumed.

8 Conclusion

What worked

  • Frozen transformer → strong features, minutes to train
  • Engineered agro-meteorology → verified independent signal
  • Physics loss → agronomic behaviour without overriding data
  • Multi-horizon head → detection becomes anticipation

Future scope

  • Drone and satellite multispectral imagery
  • Live forecast forcing instead of reanalysis
  • IoT canopy sensors for measured leaf wetness
  • Validation against recorded outbreak records
